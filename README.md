# 📚 Flashcard Quiz App (CodeAlpha Internship)

## 🚀 Overview
This Flashcard Quiz App is a simple web-based learning tool built as part of the CodeAlpha App Development Internship. It helps users study using flashcards with questions and answers in an interactive way.

---

## ✨ Features
- 📌 View flashcards (Question & Answer)
- 👁️ Show / Hide answers
- ⏭️ Next and Previous navigation
- ➕ Add new flashcards dynamically
- 🎨 Clean and modern UI design
- ⚡ Simple and fast performance

---

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript (Vanilla JS)

---

## 📁 Project Structure
Flashcard-App/
│
├── index.html
├── style.css
└── script.js

---

## 🎯 How to Use
1. Open `index.html` in any browser  
2. View flashcard questions  
3. Click **Show Answer** to reveal answer  
4. Use **Next / Previous** buttons to navigate  
5. Add your own flashcards using input fields
